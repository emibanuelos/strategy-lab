# 🔬 Strategy Lab — Análisis de Estrategias de Trading

Herramienta web para análisis, revisión y supervisión de estrategias de trading algorítmico.

## 📸 Características

- 📊 Registro y análisis de rondas de estrategias
- 🔍 Revisión detallada con métricas clave
- 📋 Supervisión y seguimiento de estrategias
- 📈 Estadísticas y visualización de datos
- 💾 Datos guardados en localStorage del navegador

## 🌐 Usar Online

👉 [https://emibanuelos.github.io/strategy-lab/](https://emibanuelos.github.io/strategy-lab/)

## 📥 Descargar y Usar Localmente

### Opción 1: Descargar ZIP (más fácil)

1. Click en el botón verde **"Code"** arriba
2. Click en **"Download ZIP"**
3. Descomprime el archivo
4. Abre `index.html` en tu navegador

### Opción 2: Clonar con Git

```bash
git clone https://github.com/emibanuelos/strategy-lab.git
cd strategy-lab
open index.html
```

## 🚀 Cómo Empezar

1. Abre `index.html` en tu navegador (Chrome recomendado)
2. Explora las diferentes secciones desde la navegación
3. Empieza a registrar tus estrategias

## 📁 Archivos

| Archivo | Descripción |
|---------|-------------|
| `index.html` | Página principal |
| `styles.css` | Tema oscuro premium |
| `data.js` | Manejo de datos y localStorage |
| `app.js` | Lógica principal de la aplicación |
| `modules.js` | Módulos de revisión, supervisión y estadísticas |

## ⚠️ Notas

- No requiere servidor ni instalación — solo abre el HTML
- Los datos se guardan en el navegador (localStorage)
- Cada navegador/dispositivo tiene sus propios datos independientes
